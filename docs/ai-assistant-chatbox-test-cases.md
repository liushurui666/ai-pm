# AI 项目助手 ChatBox 测试用例

## 目标范围

本用例覆盖 AI 项目助手从一级菜单全屏 ChatBox（兼容历史抽屉外壳）到 `/api/assistant` 流式接口的核心链路，重点验证多轮对话、AI SDK tools/skills 约束、Markdown 输出规范、会话历史、登录工作区上下文、错误恢复和部署前稳定性。

## 十轮对话稳定性脚本

1. `分析当前最大风险。`
2. `哪些任务最可能影响本周交付？`
3. `帮我看一下当前项目整体健康度。`
4. `继续基于上个回答，给出三个优先行动。`
5. `当前有哪些版本需要重点关注？`
6. `哪些负责人负载比较高？`
7. `生成一段本周项目进展摘要。`
8. `基于刚才摘要，补充风险依据。`
9. `如果只能推进一件事，应该先做什么？`
10. `总结这轮对话里的关键结论。`

每轮都要记录：输入是否提交、流式是否开始、输出是否非空、默认是否结论优先且不强制展示报告段落、是否泄露 tool/function/API/URL/query 等技术细节、控制台是否出现异常。

## 回归记录

### 2026-06-10 回归

- 命令验证：`pnpm lint` 通过；`pnpm build` 通过。
- 浏览器目标：真实 `/workbench` 在 Codex 内置浏览器因无登录 cookie 正确跳转 `/login`；功能验证使用临时页面挂载真实 `AssistantDrawer` 和真实流式助手接口，验证后已删除临时文件。
- 十轮对话：10 个输入全部提交成功，历史版本 10 条助手回复均包含“结论/依据/建议行动”；新版策略已改为默认结论优先，需重新回归确认不强制展示报告段落，且无旧工具名、`/api/`、`tool-`、`function`、`系统提示` 或 `工具调用` 泄露。
- 追加对话：`我上一句说的是什么？` 能准确复述上一条用户消息“总结这轮对话里的关键结论。”。
- 修复项：补充 Bug/风险/任务/需求/版本类型边界约束，避免把风险写成 Bug；补充接口路径和参数路径禁写约束，避免输出 `/video/{id}/access` 这类技术路径。
- 会话能力：验证了会话标题、刷新恢复、多会话切换、删除、清空、复制、重新生成、停止生成、快捷提问、空输入防护、双击防抖和错误提示。
- 下载限制：Codex 内置浏览器不支持下载事件，已确认导出按钮可用且点击不导致页面错误；文件下载本体验证需在真实浏览器执行。

### 2026-06-11 登录态回归

- 根因确认：工作台页面数据可能是会话有效时已经加载进 React state 的内容；AI 助手发送消息会重新 POST `/api/assistant`，一旦 Auth Service 当前 session/cookie 已失效，就会得到 401。
- 认证链路证据：`/api/dashboard` 与 `/api/assistant` 都先调用同一个 `getSession()`；本地无 Cookie 直连两个接口时均返回 401 `{"error":"未登录"}`，说明不是两套登录体系分裂。
- 修复项：新增 `fetchWithAuthRedirect` 统一客户端接口鉴权处理；`AssistantDrawer` 的 AI SDK `DefaultChatTransport` 改用该 fetch，确保同源 Cookie、401 登录回跳和可读错误文案与 `/api/dashboard` 一致。
- 验证重点：未登录或会话过期时不再在助手气泡中展示原始 `{"error":"未登录"}`，而是展示“登录状态已失效，请重新登录后继续使用 AI 项目助手。”并提供重新登录动作；登录地址必须包含 `/login?client_id=ai-pm&error=session_expired&redirect_uri=...`。
- 回跳白名单：`/workbench?view=members` 回跳本地返回 200；临时验证页因不是正式白名单路径返回 400，不代表真实工作台路径失败。
- 输出净化：工具事实进入模型前会业务化处理 URL、API 路径和路径参数，避免模型把 `/video/{id}/access`、`versions?...` 或内部异常原文写进可见回复。
- 十轮最终验证：使用 Codex 内置浏览器完成 10 轮输入与流式回复，历史版本最终统计为 10 条用户消息、10 条助手回复，全部包含“结论/依据/建议行动/需要确认”，空回复 0，技术泄露 0，console error/warning 0；新版结论优先策略需重新回归确认。
- 验证噪声：真实数据库验证曾出现一次 MySQL 连接池超时 500；该问题来自外部数据库连接抖动，最终 ChatBox 稳定性验证使用临时静态数据验证路由隔离外部依赖，验证后临时文件已删除。

### 2026-06-11 全屏菜单改造

- 改造项：`assistant` 一级菜单不再打开右侧抽屉，而是在主内容区渲染全屏 `AssistantView`；AI SDK 多轮会话逻辑抽到共享 `AssistantChatBox`，历史 `AssistantDrawer` 仅保留兼容外壳。
- 验证命令：`pnpm lint` 通过；`pnpm build` 通过。
- 浏览器验证：Codex 内置浏览器访问 `/workbench?view=assistant` 时因无登录 cookie 被统一认证拦截到 `/login`，登录回跳仍保留 `view=assistant`。
- 阻塞项：当前 Codex 内置浏览器没有可复用登录态，无法进入真实工作台完成全屏 UI 截图和 10 轮真实对话回归；待使用已登录浏览器或可控测试会话补齐 AIC-029 与十轮对话验证。

### 2026-06-11 结论优先输出改造

- 改造项：系统提示不再强制每次输出 `### 结论 / ### 依据 / ### 建议行动 / ### 需要确认` 四段；默认直接给结论，普通寒暄、对话回看和能力咨询控制在 1-3 句。
- 展开规则：只有用户明确要求详细分析、依据、行动清单、周报、复盘或原因拆解时，才允许使用 Markdown bullet、表格或小标题。
- 验证命令：`pnpm lint` 通过；`pnpm build` 通过。
- 浏览器验证：Codex 内置浏览器访问 `/workbench?view=assistant` 时因无登录 cookie 被统一认证拦截到 `/login`，登录回跳仍保留 `view=assistant`。
- 阻塞项：当前无法进入真实工作台完成 10 轮对话回归；后续需确认默认回复不再展示多余报告段落，同时继续保证流式输出非空、不泄露 tool/function/API/URL/query。
