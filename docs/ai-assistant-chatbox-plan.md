# AI 助手 ChatBox 流式多轮改造计划

## 背景

- 当前 AI 助手是一次性 `POST /api/assistant` 返回 JSON 文本，前端只把用户问题和助手回复追加到本地数组。
- 目标是改造成基于 AI SDK 的 ChatBox，支持多轮对话、流式输出、规范 Markdown 回复，并且所有项目分析能力必须通过 AI SDK tools 暴露给模型调用。
- 模型默认切换为 `qwen3.7-max`，继续兼容现有 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL` 环境变量。

## 约束

- AI 助手的项目分析能力必须基于 tools/skills 扩展，不允许新增手写封装函数直接替模型完成判断或拼接最终分析结论。
- 服务端工具只返回结构化项目数据或执行明确能力，最终分析、取舍和表达由模型基于工具结果完成。
- 回复必须使用规范 Markdown，结构固定、层级清晰，不能输出散乱纯文本。
- 必须支持多轮对话，服务端每轮接收历史消息并保留上下文。
- 必须支持流式输出，前端展示要能看到助手回复逐步生成。
- 修改需遵守项目 `AI-CONSTRAINTS.md`：组件目录结构、领域化 `src/lib/ai/` 文件、中文注释、本地验证、提交推送。

## 实施步骤

1. **依赖与模型配置**
   - 安装 `ai`、`@ai-sdk/react`、`@ai-sdk/openai-compatible`、`zod`。
   - 将 AI 默认模型从 `qwen-plus` 调整为 `qwen3.7-max`。
   - 同步更新运行时环境示例，确保部署默认值一致。

2. **AI SDK 服务端接入**
   - 将 `/api/assistant` 改为 AI SDK UI Message 流式接口。
   - 使用 `streamText`、`convertToModelMessages`、`toUIMessageStreamResponse` 输出流。
   - 继续保留登录与工作区权限校验。

3. **工具能力建设**
   - 在 `src/lib/ai/` 下建立助手工具模块。
   - 提供项目概览、风险任务、版本范围、成员负载、周报上下文等工具。
   - 工具返回结构化数据，避免在工具中直接生成最终自然语言结论。

4. **回复格式规范**
   - 新增助手系统提示词，固定输出结构：
     - `### 结论`
     - `### 依据`
     - `### 建议行动`
     - `### 需要确认`
   - 约束无工具依据不得编造项目事实。
   - 约束建议行动最多 3 条，避免输出失控。

5. **前端 ChatBox 改造**
   - `AssistantDrawer` 接入 `useChat`，支持发送、停止生成、重新生成和错误态。
   - 消息渲染按 AI SDK `parts` 展示流式文本。
   - 输入框保留当前抽屉体验，移动端与桌面端都要可用。

6. **周报导出兼容**
   - 保留非聊天导出的稳定路径，避免右上角 Markdown 周报下载被流式接口破坏。
   - 聊天中用户要求周报时，通过 tools 读取上下文并由模型生成规范回答。

7. **项目约束补充**
   - 将本次要求写入 `AI-CONSTRAINTS.md`。
   - 以后修改 AI 助手能力时，必须以 AI SDK tools/skills 为扩展边界，并通过浏览器多轮稳定性验证。

8. **本地验证**
   - 执行 `pnpm lint`。
   - 涉及构建链路或类型变更时执行 `pnpm build`。
   - 启动 `pnpm dev`。
   - 使用 Codex 内置浏览器打开 `/workbench`，完成至少 10 轮基础对话验证。
   - 每轮不仅验证输入提交，还验证助手输出能稳定生成、格式规范、没有空回复或前端报错。

## 浏览器十轮验证问题

1. 分析当前最大风险。
2. 哪些任务最可能影响本周交付？
3. 帮我看一下当前项目整体健康度。
4. 继续基于上个回答，给出三个优先行动。
5. 当前有哪些版本需要重点关注？
6. 哪些负责人负载比较高？
7. 生成一段本周项目进展摘要。
8. 基于刚才摘要，补充风险依据。
9. 如果只能推进一件事，应该先做什么？
10. 总结这轮对话里的关键结论。

## 完成标准

- AI 助手抽屉可连续进行至少 10 轮多轮对话。
- 每轮输出为流式生成，最终文本不为空。
- 输出结构包含固定 Markdown 标题，格式稳定。
- 模型通过 tools 获取项目数据，服务端不再手写最终分析结论。
- `AI_MODEL` 默认值为 `qwen3.7-max`。
- `AI-CONSTRAINTS.md` 已记录后续扩展约束。
- 本地 lint/build 与浏览器验证结果可复述。
